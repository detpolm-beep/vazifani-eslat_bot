# 🤖 Vazifa Eslatuvchi Telegram Bot

## O'rnatish

### 1. Python o'rnatish
https://www.python.org/downloads/ dan Python 3.10+ yuklab oling.
O'rnatishda **"Add Python to PATH"** katagini belgilang!

### 2. Kutubxonalarni o'rnatish
```
pip install -r requirements.txt
```

### 3. Botni ishga tushirish
```
python bot.py
```
yoki `start.bat` faylini ikki marta bosing.
